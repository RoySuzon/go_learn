Lesson 01: Hello World & Structure (সূচনা ও প্রোগ্রামের গঠন)

lesson01/01_introduction.go

ব্যাখ্যা: প্রতিটি এক্সিকিউটেবল Go প্রোগ্রাম package main দিয়ে শুরু হতে হয়। import "fmt" ইনপুট/আউটপুটের জন্য ব্যবহৃত হয় এবং func main() হলো প্রোগ্রামের মূল এন্ট্রি পয়েন্ট। 

package main

import "fmt"

func main() {
    fmt.Println("Hello, World! গো প্রোগ্রামিং-এ স্বাগতম।")
}

Lesson 02: Variables, Constants & Data Types (ভ্যারিয়েবল ও টাইপ)

lesson02/02_variables_types.go

ব্যাখ্যা: Go-তে ভ্যারিয়েবল ডিক্লেয়ারেশনের ৩টি নিয়ম রয়েছে (Explicit, Infer, `:=`)। কোনো মান না দিলে ডিফল্ট Zero Value (0, 0.0, false, "") অ্যাসাইন হয়। iota ক্রমানুসারে কনস্ট্যান্ট উৎপন্ন করে। 

var name string = "Goutom"
age := 26

const (
    Pending = iota // 0
    Approved       // 1
)

Lesson 03: Control Flow (কন্ট্রোল ফ্লো: `if`, `switch`, `for`)

lesson03/03_control_flow.go

ব্যাখ্যা: if স্টেটমেন্টের সাথে শর্ট ভ্যারিয়েবল ডিক্লেয়ার করা যায়। switch কেসের শেষে স্বয়ংক্রিয়ভাবে break হয়। Go-তে একমাত্র লুপ হলো for। 

if limit := 100; score < limit {
    fmt.Println("Valid score")
}

for i := 1; i <= 3; i++ {
    fmt.Println(i)
}

Lesson 04: Functions & Error Handling (ফাংশন ও এরর হ্যান্ডলিং)

lesson04/04_functions_errors.go

ব্যাখ্যা: Go ফাংশন থেকে একাধিক মান (result, error) রিটার্ন করা যায়। defer ফাংশন শেষে স্থগিত কাজ সম্পন্ন করে (LIFO), আর panic এবং recover প্রোগ্রাম ক্র্যাশ হ্যান্ডেল করে। 

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("cannot divide by zero")
    }
    return a / b, nil
}

Lesson 05: Data Structures (অ্যারে, স্লাইস, ম্যাপ ও স্ট্রাক্ট)

lesson05/05_data_structures.go

ব্যাখ্যা: স্লাইস হলো ডায়নামিক আকারের অ্যারে ভিউ (`append()`, `make()`)। ম্যাপ হলো কী-ভ্যালু হ্যাশ টেবিল। গো-তে ক্লাসের বদলে **Struct Embedding (Composition)** ব্যবহৃত হয়। 

type User struct {
    ID   int
    Name string
}

languages := []string{"Go", "Python"}
languages = append(languages, "Rust")

Lesson 06: Pointers & Memory (পয়েন্টার ও মেমোরি)

lesson06/06_pointers.go

ব্যাখ্যা: & দিয়ে মেমোরি ঠিকানা পাওয়া যায় এবং * দিয়ে পয়েন্টার ডিরেক্ট করা যায়। Go সম্পূর্ণভাবে **Pass-by-Value** মেনে চলে; তাই মূল ভ্যারিয়েবল পরিবর্তন করতে পয়েন্টার পাঠাতে হয়। 

val := 42
ptr := &val

*ptr = 100 // Modifies original val directly

Lesson 07: Methods & Interfaces (মেথড ও ইন্টারফেস)

lesson07/07_methods_interfaces.go

ব্যাখ্যা: Value Receiver মূল অবজেক্ট কাস্ট করে না, তবে Pointer Receiver রিড/রাইট কাস্ট করতে পারে। `implements` ছাড়াই Go-তে টাইপসমূহ **Implicitly Interface** বাস্তবায়ন করে। 

type Shape interface {
    Area() float64
}

func (c Circle) Area() float64 {
    return math.Pi * c.Radius * c.Radius
}

Lesson 08: Concurrency, Goroutines & Channels (কনকারেন্সি)

lesson08/08_concurrency.go

ব্যাখ্যা: go কিওয়ার্ড দিয়ে খুব লাইটওয়েট থ্রেড (Goroutine - ~2KB) চালু করা যায়। চ্যানেলের মাধ্যমে থ্রেডগুলোর মধ্যে তথ্য আদান-প্রদান করা হয়। sync.Mutex রেস কন্ডিশন প্রতিরোধ করে। 

ch := make(chan string)

go func() {
    ch <- "গোরুটিন থেকে সফলভাবে বার্তা প্রাপ্ত!"
}()

msg := <-ch
fmt.Println(msg)

Lesson 09: Modules & Standard Library (মডিউল ও স্ট্যান্ডার্ড লাইব্রেরি)

lesson09/09_modules_stdlib.go

ব্যাখ্যা: `Capitalized` আদ্যক্ষরের নাম হলো Public/Exported, এবং `lowercase` হলো Private। গুরুত্বপূর্ণ স্ট্যান্ডার্ড প্যাকেজ: `strings`, `strconv`, `time`, `os`। 

trimmed := strings.TrimSpace("  Go  ")
num, _ := strconv.Atoi("100")
now := time.Now().Format("2006-01-02 15:04:05")

Lesson 10: Unit Testing & Benchmarking (ইউনিট টেস্ট ও বেঞ্চমার্ক)

lesson10/10_unit_testing_test.go

ব্যাখ্যা: Go-এর নিজস্ব `testing` প্যাকেজ ব্যবহার করে `testing.T` দিয়ে স্বয়ংক্রিয় টেস্ট, Table-Driven Tests, এবং `testing.B` দিয়ে পারফরম্যান্সের বেঞ্চমার্ক মাপা হয়। 

func TestAdd(t *testing.T) {
    if got := Add(10, 20); got != 30 {
        t.Errorf("Add(10, 20) = %d; want 30", got)
    }
}

🧠 Core Data Structures & Algorithms

1. Singly Linked List

Head pointer, Insert, Delete node, Search (O(N) search, O(1) head insertion).

[Head] -> [10|Next] -> [20|Next] -> NIL

2. Binary Search Tree (BST)

Left child < Parent < Right child. In-Order traversal returns sorted elements.

   (50)
  /    \
(30)  (70)

🚀 Advanced DSA Algorithms

1. Trie (Prefix Tree)

Fast string prefix matching O(L) for Autocomplete.

Root -> 'g' -> 'o' -> 'l' -> 'a' -> 'n' -> 'g'

2. Min-Heap Priority Queue

O(log N) Priority Queue for scheduling.

Pop() returns minimum item instantly (O(1))
