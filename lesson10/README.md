# Lesson 10: Unit Testing & Benchmarking (ইউনিট টেস্ট ও পারফরম্যান্স)

## 📝 Overview (সংক্ষিপ্ত পরিচয়)
Go-এর নিজস্ব `testing` প্যাকেজ দিয়ে ইউনিট টেস্ট, টেবিল-ড্রাইভেন টেস্ট এবং বেঞ্চমার্ক তৈরি।

---

## 🔑 Key Concepts (মূল ধারণাসমূহ)

1. **`testing.T`**: ফাংশনের সঠিকতা যাচাই করার জন্য ইউনিট টেস্ট।
2. **Table-Driven Tests**: একাধিক টেস্ট কেস অ্যারে/স্লাইসের মধ্যে রেখে লুপ চালিয়ে টেস্ট করা (Go-এর বেস্ট প্র্যাকটিস)।
3. **`testing.B`**: ফাংশনের এক্সিকিউশন টাইম এবং মেমোরি পারফরম্যান্স মাপার জন্য বেঞ্চমার্ক টেস্ট।

---

## 🚀 How to Run (কোড চালনার নিয়ম)
```bash
# ইউনিট টেস্ট রান করা
go test -v ./lesson10/...

# বেঞ্চমার্ক টেস্ট রান করা
go test -bench=. ./lesson10/...
```
