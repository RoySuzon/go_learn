# Lesson 04: Functions & Error Handling (ফাংশন ও এরর হ্যান্ডলিং)

## 📝 Overview (সংক্ষিপ্ত পরিচয়)
Go-তে ফাংশন একাধিক মান রিটার্ন করতে পারে এবং এরর হ্যান্ডলিংয়ের জন্য বিশেষ কিওয়ার্ডসমূহ ব্যবহৃত হয়।

---

## 🔑 Key Concepts (মূল ধারণাসমূহ)

1. **Multiple Return Values**: সাধারণভাবে `(result, error)` প্যাটার্ন রিটার্ন করা হয়।
2. **Named Returns & Variadic Functions**: রিটার্ন ভ্যারিয়েবলের নাম নির্ধারণ ও অননির্দিষ্ট সংখ্যক আর্গুমেন্ট গ্রহণ (`numbers ...int`)।
3. **Closures**: ফাংশন যা তার বাইরের স্কোপের ভ্যারিয়েবল মনে রাখে।
4. **`defer`**: ফাংশনের কাজ শেষ হওয়া পর্যন্ত এক্সিকিউশন স্থগিত রাখে (LIFO অর্ডার)।
5. **`panic` & `recover`**: প্যানিক হ্যান্ডেল করে প্রোগ্রাম ক্র্যাশ থেকে বাঁচানো।

---
