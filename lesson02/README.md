# Lesson 02: Variables, Constants & Data Types (ভ্যারিয়েবল, কনস্ট্যান্ট ও টাইপ)

## 📝 Overview (সংক্ষিপ্ত পরিচয়)
Go-তে ভ্যারিয়েবল ডিক্লেয়ারেশনের একাধিক নিয়ম রয়েছে এবং কোনো মান না দিলে ডিফল্ট **Zero Value** অ্যাসাইন হয়।

---

## 🔑 Key Concepts (মূল ধারণাসমূহ)

1. **Short Variable Declaration (`:=`)**: ফাংশনের ভেতরে দ্রুত ভ্যারিয়েবল ডিক্লেয়ার ও ইনিশিয়ালাইজ করার জন্য।
2. **Zero Values (জিরো ভ্যালু)**:
   - `int`: `0`
   - `float64`: `0.0`
   - `bool`: `false`
   - `string`: `""`
3. **`iota` (কনস্ট্যান্ট জেনারেটর)**: ক্রমানুসারে (0, 1, 2...) মান তৈরি করার জন্য ব্যবহৃত হয়।
4. **Explicit Type Casting**: Go-তে কোনো স্বয়ংক্রিয় টাইপ রূপান্তর হয় না। স্পষ্ট কাস্টিং করতে হয় (`float64(a)`)।
