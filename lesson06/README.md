# Lesson 06: Pointers & Memory (পয়েন্টার ও মেমোরি ম্যানেজমেন্ট)

## 📝 Overview (সংক্ষিপ্ত পরিচয়)
পয়েন্টার হলো ভ্যারিয়েবলের মেমোরি অ্যাড্রেস ধারণকারী টাইপ। Go সম্পূর্ণভাবে **Pass-by-Value** মেনে চলে।

---

## 🔑 Key Concepts (মূল ধারণাসমূহ)

1. **`&` (Address-of Operator)**: কোনো ভ্যারিয়েবলের মেমোরি ঠিকানা নেওয়ার জন্য।
2. **`*` (Dereference Operator)**: মেমোরি ঠিকানায় থাকা মান পড়া বা পরিবর্তন করার জন্য।
3. **Pass-by-Pointer**: ফাংশনের মধ্যে মূল ভ্যারিয়েবলের মান পরিবর্তন করতে পয়েন্টার পাঠানো হয়।
