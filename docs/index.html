Lesson 01: Hello World & Structure (সূচনা ও প্রোগ্রামের গঠন)

lesson01/01_introduction.go

ব্যাখ্যা: প্রতিটি রানঅ্যাবল Go প্রোগ্রাম package main দিয়ে শুরু হতে হয়। import "fmt" দিয়ে ইনপুট-আউটপুট প্যাকেজ সংযুক্ত করা হয় এবং func main() হলো প্রোগ্রামের মূল এন্ট্রি পয়েন্ট। 

package main

import "fmt"

func main() {
    fmt.Println("Hello, World! গো প্রোগ্রামিং-এ স্বাগতম।")
}

Lesson 08: Concurrency, Goroutines & Channels (কনকারেন্সি)

lesson08/08_concurrency.go

ব্যাখ্যা: go কিওয়ার্ড দিয়ে খুব লাইটওয়েট থ্রেড (Goroutine - ~2KB) চালু করা যায়। চ্যানেলের মাধ্যমে থ্রেডগুলোর মধ্যে তথ্য আদান-প্রদান করা হয়। sync.Mutex রেস কন্ডিশন প্রতিরোধ করে। 

ch := make(chan string)

go func() {
    ch <- "গোরুটিন থেকে সফলভাবে বার্তা প্রাপ্ত!"
}()

msg := <-ch
fmt.Println(msg)
