# Lesson 01: Introduction & Program Structure (সূচনা ও প্রোগ্রামের গঠন)

## 📝 Overview (সংক্ষিপ্ত পরিচয়)
গো (Go/Golang) হলো গুগল কর্তৃক তৈরি একটি হাই-পারফরম্যান্স, স্ট্যাটিকারি টাইপড এবং কম্পাইল্ড প্রোগ্রামিং ভাষা।

---

## 🔑 Key Concepts (মূল ধারণাসমূহ)

1. **`package main`**: গো কম্পাইলারকে নির্দেশ করে যে এই ফাইলটি একটি এক্সিকিউটেবল প্রোগ্রাম।
2. **`import (...)`**: স্ট্যান্ডার্ড বা থার্ড-পার্টি লাইব্রেরি যুক্ত করার জন্য ব্যবহৃত হয়।
3. **`func main()`**: প্রোগ্রামের মূল এন্ট্রি পয়েন্ট। এটি সম্পন্ন হলে প্রোগ্রাম শেষ হয়।

---

## 💻 Sample Code (কোড উদাহরণ)

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, World! গো প্রোগ্রামিং-এ স্বাগতম।")
}
```

```bash
go run ./lesson01/01_introduction.go
```
